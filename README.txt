EmoStream Website
=================

How to open:
1. Extract the ZIP file.
2. Open index.html with Google Chrome, Microsoft Edge, or Firefox.

No installation is required.

Note: Browser permission may be required for camera and microphone features.

開啟方式：
1. 解壓縮 ZIP 檔案。
2. 使用 Google Chrome、Microsoft Edge 或 Firefox 開啟 index.html。

不需要安裝。相機或麥克風功能可能需要瀏覽器權限。
